# Project rules

This project's rules live in `AGENTS.md` at the repository root. Before doing
any work, read `AGENTS.md` and follow it exactly: the 20-phase release
workflow, PHP coding standards, security baseline, and the mandatory README +
changelog sync. The same file is the single source of truth for Claude Code
(`CLAUDE.md`), Cline CLI, Codex CLI and OpenCode; this rule exists only so
Antigravity (CLI and IDE) loads the same instructions.
